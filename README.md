# สมุดยิม (PWA)

**เปิดใช้งาน:** https://paphontee.github.io/Gym/

แอปบันทึกการเล่นยิม ติดตั้งลงมือถือได้ ใช้งานออฟไลน์ได้ ข้อมูลอยู่ในเครื่องของคุณ และซิงก์กับ Google Drive ของคุณเองได้ ไม่มีเซิร์ฟเวอร์กลาง

## ไฟล์ในโปรเจกต์

| ไฟล์ | หน้าที่ |
| --- | --- |
| `index.html` | โครงหน้าเว็บ |
| `styles.css` | หน้าตาแอป (สี ตัวอักษร โหมดมืด) |
| `app.js` | โค้ดทั้งหมดของแอป |
| `config.js` | ที่ใส่ Google Client ID (ไม่ใส่ก็ได้) |
| `sw.js` | service worker ทำให้ใช้ออฟไลน์ได้ |
| `manifest.webmanifest` | ชื่อ ไอคอน และสีของแอปตอนติดตั้ง |
| `icons/` | ไอคอนแอป |

## 1. เอาขึ้นเว็บด้วย GitHub Pages (ฟรี)

1. สมัคร [github.com](https://github.com) แล้วกด **New repository** ตั้งชื่อเช่น `gymlog` เลือก **Public** แล้วกด Create
2. กด **Add file > Upload files** ลากไฟล์ทั้งหมดในโฟลเดอร์นี้ลงไป (รวมโฟลเดอร์ `icons`) แล้วกด **Commit changes**
3. ไปที่ **Settings > Pages** ตรง Source เลือก **Deploy from a branch** เลือก branch `main` โฟลเดอร์ `/ (root)` แล้วกด Save
4. รอประมาณ 1–2 นาที แอปจะอยู่ที่ `https://ชื่อผู้ใช้.github.io/gymlog/`

repo แบบ Public หมายถึงโค้ดเป็นสาธารณะ แต่ข้อมูลการฝึกของคุณไม่ได้อยู่ใน repo มันอยู่ในเครื่องและใน Drive ของคุณเท่านั้น

ใช้ Netlify หรือ Cloudflare Pages แทนได้ แค่ลากโฟลเดอร์นี้ไปวาง

## 2. ติดตั้งลงมือถือ

- **iPhone:** เปิดลิงก์ใน Safari แล้วกดปุ่มแชร์ จากนั้นกด **เพิ่มไปยังหน้าจอโฮม**
- **Android:** เปิดใน Chrome แล้วกดปุ่ม **ติดตั้งแอป** ในหน้าตั้งค่าของแอป หรือจากเมนู ⋮

## 3. ย้ายข้อมูลจากเวอร์ชันใน Claude

1. เปิดสมุดยิมเวอร์ชันเดิม ไปที่ **ตั้งค่า > ดาวน์โหลดไฟล์สำรอง (.json)**
2. เปิดแอปใหม่ ไปที่ **ตั้งค่า > กู้คืนจากไฟล์สำรอง** แล้วเลือกไฟล์นั้น

## 4. ซิงก์กับ Google Drive (ไม่บังคับ)

แอปจะเก็บไฟล์ `gymlog-data.json` ไว้ในโฟลเดอร์ซ่อนเฉพาะของแอปใน Drive ของคุณ (appDataFolder) ไฟล์นี้จะไม่โผล่ในรายการไฟล์ปกติ และแอปขอสิทธิ์เข้าถึงแค่โฟลเดอร์นี้ ไฟล์อื่นใน Drive อ่านไม่ได้

### ขอ Client ID (ทำครั้งเดียว ประมาณ 10 นาที)

1. เข้า [console.cloud.google.com](https://console.cloud.google.com) แล้วสร้างโปรเจกต์ใหม่ เช่น `gymlog`
2. ไปที่ **APIs & Services > Library** ค้นหา **Google Drive API** แล้วกด **Enable**
3. ไปที่ **OAuth consent screen** (หรือ Google Auth Platform)
   - User type เลือก **External**
   - ใส่ชื่อแอปและอีเมลของคุณ
   - ที่ Scopes ให้เพิ่ม `https://www.googleapis.com/auth/drive.appdata`
   - ที่ **Test users** เพิ่ม Gmail ของคุณเอง แล้วปล่อยแอปไว้ในโหมด Testing (ใช้คนเดียวไม่ต้องส่งให้ Google ตรวจ)
4. ไปที่ **Credentials > Create credentials > OAuth client ID**
   - Application type เลือก **Web application**
   - ที่ **Authorized JavaScript origins** ใส่ `https://ชื่อผู้ใช้.github.io` (ไม่ต้องมี /gymlog และไม่มี / ปิดท้าย)
   - กด Create แล้วคัดลอก Client ID (ลงท้ายด้วย `.apps.googleusercontent.com`)
5. เปิด `config.js` วาง Client ID ลงใน `googleClientId: ''`
6. เปิด `sw.js` แก้ `VERSION` เป็นเลขใหม่ เช่น `gymlog-v2` แล้วอัปโหลดทั้งสองไฟล์ขึ้น GitHub
7. ในแอปไปที่ **ตั้งค่า > เชื่อมต่อ Google Drive** แล้วล็อกอิน

### การทำงาน

- พอล็อกอินแล้ว แอปจะซิงก์ให้อัตโนมัติหลังบันทึกทุกครั้ง และตอนปิดแอป
- สิทธิ์จาก Google อยู่ได้ประมาณ 1 ชั่วโมง พอเปิดแอปครั้งถัดไปจะมีแถบ **แตะเพื่อซิงก์** ขึ้นมา ให้กดหนึ่งครั้ง (Google กำหนดว่าการล็อกอินต้องมาจากการแตะของผู้ใช้)
- ถ้าใช้หลายเครื่อง ข้อมูลจะรวมกันเป็นรายวัน วันไหนแก้ล่าสุดจะใช้ของวันนั้น
- บน iPhone บางรุ่น หน้าต่างล็อกอินของ Google อาจไม่เปิดในแอปที่ติดตั้งบนหน้าจอโฮม ถ้าเจอแบบนี้ ให้เปิดเว็บใน Safari เพื่อซิงก์ หรือใช้ไฟล์สำรองแทน
- ดูหรือลบสิทธิ์ได้ที่ Google Drive > การตั้งค่า > จัดการแอป

## 5. การแจ้งเตือน

ไปที่ **ตั้งค่า > การแจ้งเตือน** เลือกเวลาไปยิมและเวลาเตือนล่วงหน้า แล้วกด **ดาวน์โหลดไฟล์ปฏิทิน (.ics)**

- **iPhone:** เปิดไฟล์แล้วกด **เพิ่มทั้งหมด** ลงปฏิทิน
- **Google Calendar:** เปิดบนคอมพิวเตอร์ ไปที่ **การตั้งค่า > นำเข้าและส่งออก** แล้วเลือกไฟล์

ถ้าแก้วันในโปรแกรม ให้ลบนัดเก่าในปฏิทินก่อน แล้วค่อยเพิ่มไฟล์ใหม่ ถ้าใช้ปฏิทินแล้ว ลบการเตือนใน Reminders ที่ตั้งไว้ก่อนหน้าได้ จะได้ไม่เตือนซ้ำ

### ตัวจับเวลาพักระหว่างเซ็ต

ตั้งค่าได้ที่ **ตั้งค่า > ตัวจับเวลาพัก** เมื่อหมดเวลาแอปจะสั่นและส่งเสียง และถ้าเปิด **แจ้งเตือนนอกแอป** ไว้ จะส่งการแจ้งเตือนของเครื่องเมื่อคุณอยู่แอปอื่น

- **Android:** ทำงานได้ทั้งตอนสลับแอปและล็อกจอ
- **iPhone:** ต้องเพิ่มแอปไปยังหน้าจอโฮม (iOS 16.4 ขึ้นไป) และ iOS จะหยุดเว็บแอปทันทีที่ไม่อยู่บนจอ ตัวจับเวลาจึงเดินต่อเฉพาะตอนแอปอยู่บนจอ แนะนำเปิด **กันหน้าจอดับระหว่างพัก** ไอคอนบน Dynamic Island / Live Activity เป็นความสามารถเฉพาะแอปจาก App Store เว็บแอปทำไม่ได้

## 6. แก้ไขและพัฒนาต่อ

ทดสอบบนคอมพิวเตอร์ด้วยคำสั่งนี้ในโฟลเดอร์โปรเจกต์ แล้วเปิด `http://localhost:8000`

```
python3 -m http.server 8000
```

ถ้าจะทดสอบ Google Drive บนเครื่องตัวเอง ให้เพิ่ม `http://localhost:8000` ใน Authorized JavaScript origins ด้วย

**ทุกครั้งที่แก้ไฟล์ ต้องแก้ `VERSION` ใน `sw.js` และ `APP_VERSION` ใน `app.js` ให้เป็นเลขเดียวกัน** ไม่อย่างนั้นมือถือจะใช้ไฟล์เก่าจากแคช พอแก้แล้ว แอปจะขึ้นแถบ "มีเวอร์ชันใหม่" ให้กดอัปเดต

ส่วนสำคัญใน `app.js`

| ส่วน | ทำอะไร |
| --- | --- |
| `DEFAULT_PROGRAM` | โปรแกรมเริ่มต้น |
| `lsLoad`, `lsSave`, `save`, `mergeIn` | อ่าน เขียน และรวมข้อมูลในเครื่อง |
| `Drive` | ซิงก์กับ Google Drive |
| `suggest`, `overload`, `goalInfo` | คำแนะนำเพิ่มน้ำหนัก (ใช้ RIR ของครั้งก่อนด้วย) เช็ก progressive overload และเป้าหมาย |
| `rirHTML` | ถาม RIR (เหลือแรงอีกกี่ครั้ง) หลังจบเซ็ต เก็บใน `set.rir` และส่งออกใน CSV |
| `MG_RULES`, `mgOf`, `mgVolumeHTML` | กล้ามเนื้อที่ใช้ต่อท่า (เดาจากชื่อ หรือระบุใน `ex.mg`) และปริมาณงานต่อกล้ามเนื้อต่อสัปดาห์ในหน้าสรุป |
| `foldSet`, `foldSave` | พับ/กางการ์ดท่าในแท็บวันนี้ (เก็บใน localStorage รายวัน ไม่ซิงก์) |
| `deloadDue`, `deloadHTML`, `resetOf` | เสนอสัปดาห์ deload (ครบ N สัปดาห์หรือติดที่เดิมหลายท่า) ใช้น้ำหนัก 60% ระหว่าง deload และปุ่มลด 10% รายท่า (`profile.deload`, `profile.reset`) |
| `calcCompute` | เครื่องคิดสารอาหาร (BMR, TDEE, สัดส่วน) |
| `plateCalc`, `renderPlate` | เครื่องคิดแผ่นน้ำหนัก (ปุ่ม "แผ่น" ในแท็บวันนี้ ตั้งค่าบาร์และแผ่นที่มีในหน้าตั้งค่า) |
| `renderHist`, `openSheet` | ประวัติท่าต่อท่า (แตะชื่อท่า) และแผง bottom sheet ที่ใช้ร่วมกัน |
| `warmOn`, `warmPlan`, `warmHTML` | เซ็ตวอร์มอัพอัตโนมัติ (เก็บใน `session.warm` แยกจากเซ็ตจริง เปิดปิดรายท่าด้วย `ex.warm`) |
| `renderToday`, `renderFood`, `renderProgress`, `renderReport`, `renderSettings`, `renderEditor`, `renderCalc` | หน้าจอแต่ละหน้า |
| listener `click` ท้ายไฟล์ | จัดการทุกปุ่มผ่าน `data-act` |

## ข้อควรรู้เรื่องข้อมูล

- ข้อมูลหลักอยู่ใน `localStorage` ของเบราว์เซอร์ ถ้าล้างข้อมูลเว็บไซต์ ข้อมูลจะหาย
- iPhone อาจลบข้อมูลของเว็บที่ไม่ได้เปิดนานหลายสัปดาห์ แต่แอปที่ติดตั้งบนหน้าจอโฮมจะปลอดภัยกว่า
- ข้อมูลในแอปบนหน้าจอโฮมกับใน Safari แยกกัน ให้ใช้ที่เดียว
- ควรเปิด Google Drive sync หรือดาวน์โหลดไฟล์สำรองเป็นระยะ แอปจะเตือนถ้าไม่ได้สำรองเกิน 7 วัน
